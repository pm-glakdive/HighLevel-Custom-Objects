# HighLevel Custom Objects service prototype

An interactive interview prototype showing how a service Case (custom object) can connect a customer's conversation, Contact, AC Asset, Service Agreement, and a technician's Task. The proposed **Active Case** context in Conversations is a product concept, not an existing HighLevel feature.

**[Open the live prototype](https://pm-glakdive.github.io/HighLevel-Custom-Objects/)**

See [the app README](hl-service-prototype/README.md) for the walkthrough and local setup. Demo data is stored in your browser; use **Reset demo** to start again.
